# ModCrypt

A mod-profile launcher with an undead look: **one game install, many mod profiles**. Built for 7 Days to Die (V2.6) first.

## Download
Grab `ModCrypt-win-Setup.exe` from the [latest release](https://github.com/joshcarterky/ModCrypt/releases/latest) and run it. ModCrypt updates itself after that.

Windows may show a SmartScreen warning because the installer isn't code-signed yet: choose **More info → Run anyway**.

## What it does
- Each profile has its own Mods folder and its own game settings; the base game is never copied.
- Saves and generated worlds stay in your normal 7 Days to Die folder and are shared by every profile.
- Safe mode (launch with no mods), launch options, multiple game installs, play time, tray and mini mode, automatic updates.

# Security

## Reporting a problem
Found a security issue in ModCrypt, or a mod pack that looks malicious? Please **don't** post details publicly.
Use GitHub's private report form: **Security → Report a vulnerability** on https://github.com/joshcarterky/ModCrypt.

## Staying safe
- Only download ModCrypt from https://github.com/joshcarterky/ModCrypt/releases.
- ModCrypt never needs administrator rights. If something asks you to run it as admin, don't.
- Packs that contain DLL files can run code on your PC. ModCrypt warns you before installing them; only accept packs from authors you trust.
